# Django Brand Kit

Archivos vectoriales SVG:
- django-isotype.svg
- django-isotype-inverse.svg
- django-wordmark.svg
- django-logo-stacked.svg
- django-logo-horizontal.svg
- django-app-icon.svg
- django-app-icon-dark.svg
- django-palette.svg

Estilos:
- django-colors.css
- django-tokens.json

Todos los SVG se pueden arrastrar directamente a Figma, Illustrator, Inkscape o al navegador.
El wordmark está convertido a curvas, así que no depende de tener instalada una tipografía.

Paleta principal:
- #EB0808 — rojo / CTA
- #320808 — texto oscuro, footer, superficies oscuras
- #FBEFCE — fondo principal
- #CCB68C — bordes y fondos secundarios
- #E56D58 — acentos / hover
- #571614 — texto secundario
- #A0090A — hover rojo
- #E1CFA8 — fondo secundario cálido
